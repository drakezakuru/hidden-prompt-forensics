# hidden-prompt-forensics

> **Одна строка:** форензика скрытых промптов и подлинности любого
> OpenAI-совместимого LLM-API.

Отвечает на четыре вопроса про любой шлюз, ключ или «uncensored» endpoint:

| Вопрос | Как отвечается |
|---|---|
| **Что** провайдер дописывает в каждый запрос? | эхо-пробы + сырые token ids |
| **Сколько** токенов это стоит? | арифметика `prompt_tokens` |
| **Кто** реально под брендом? | logprobs, token ids, отпечаток харнесса |
| **Настоящая** ли это сильная модель? | батарея задач с верными ответами |

---

## Зачем

Провайдеры молча добавляют свой system prompt. Иногда это персона («представляйся
нашей моделью»), иногда стиль («отвечай без морализаторства»), иногда просто
мусор, который вы оплачиваете на каждом запросе. Заявления вида «мы не добавляем
system prompt» проверяемы — и часто ложны.

Второй слой: имя в `model:` ничего не доказывает. Шлюзы подменяют модели, продают
слабую под именем сильной, перепродают чужие ключи. Скилл отделяет одно от другого.

## Установка

Ничего ставить не нужно — только `requests`:

```bash
pip install requests
```

Скрипты standalone, работают из любой папки.

## Быстрый старт

```bash
# 1. скрытый промпт + оверхед + структура блоков
python3 probe.py --base https://api.example.com/v1 --key sk-...

# 2. реальное семейство по отпечатку токенизатора
#    (работает, только если endpoint отдаёт token ids)
python3 fingerprint.py --base https://api.example.com/v1 --key sk-... \
    --candidates Qwen/Qwen3.5-9B NousResearch/Meta-Llama-3-8B

# 3. настоящая модель или переименованная — батарея задач
python3 capability_battery.py --base https://api.example.com/v1 --key sk-... \
    --model NAME
```

**Порядок работы:** сначала метод 0 (сверка имени с каталогом вендора) →
`probe.py` (что инжектится и сколько стоит) → идентичность (logprobs /
самоотчёт / token ids / отпечаток харнесса) → `capability_battery.py`.

## Что внутри

```
probe.py                 вскрытие скрытого промпта одной командой (шаги 1-5)
fingerprint.py           определение базовой модели по отпечатку токенизатора
capability_battery.py    подлинность: ядро + дискриминирующее, вердикт по классу
SKILL.md                 полный метод: 5 шагов + 4 метода идентичности + оговорки
ГДЕ-ПРОВЕРЯТЬ.md         внешние источники: каталоги вендоров, бенчмарки,
                         реестры, инструменты проверки — и чему верить
```

### `probe.py`

Арифметика токенов (два запроса с `max_tokens=1`), дифференциальные пробы
(принимается ли ваша system-роль), эхо-пробы (цитата преамбулы, инвентаризация,
чанковая суммаризация), сырые token ids и анализ структуры по позициям.

### `fingerprint.py`

Собирает `prompt_token_ids` с endpoint'а, качает кандидатов с HuggingFace,
сравнивает словари и печатает рейтинг совпадений. Даёт жёсткий ответ, когда
провайдер запрещает модели называть себя.

### `capability_battery.py`

Ядро из 5 задач, где обязаны сыпаться мелкие модели (шар и бита, «r» в
`strawberry`, `847*293`, нулей в `100!`), и дискриминирующее из 4 задач,
отделяющих фронтьер (контрпример к `n⁴+4`, перебор с ограничениями,
longest palindrome). Вердикт: фронтьер / средний класс / переименованная мелочь.

## Что уже вскрыто

В `SKILL.md` два разобранных кейса с числами:

**NoTrack** — заявлял «No system prompt of ours is added to yours». По факту
~228 скрытых токенов на каждый запрос: два блока (идентичность 77 токенов +
стиль 135). Модель обязана называть себя «NoTrack's own model» — отпечаток
токенизатора показал Qwen3.5/3.8 байт-в-байт (13 из 14 проб). Самоотчёт врал.

**9aws** — витрина из 19 моделей, отвечает одна. Скрытый инжект ~1503 токена,
идентичен на «разных» моделях → один апстрим. token ids вырезаны, но харнесс
опознан как OpenAI Responses API по `id: resp_...` и заголовкам.

## Ключевые оговорки

Скилл намеренно осторожен в выводах:

- **Имя модели и самоотчёт — не доказательство** ни в одну сторону. Модель может
  не знать собственного релизного имени, а системный промпт может запрещать
  раскрытие. Отсутствие самоидентификации доказывает **сокрытие**, а не подделку.
- **Сначала каталог вендора, потом выводы.** Незнакомое имя сверяется с
  официальным списком до любых заявлений о фальшивости.
- **Точную версию модели** можно утверждать только при наличии token ids,
  `system_fingerprint` или метаданных. Иначе — «здесь не проверяется».
- **Отказ в дословной цитате** не означает отсутствие промпта: чанковая
  суммаризация даёт темы, по которым узнаётся харнесс.
